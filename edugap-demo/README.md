# EduGap — Demo (static prototype)

เปิด `index.html` ได้ทันที ข้อมูลทั้งหมดเป็น Demo Data ในหน่วยความจำ (ไม่ใช้ Supabase, รีเฟรชแล้วรีเซ็ต)
- ผลของเพื่อนร่วมห้อง 24 คนสร้างจากตัวสุ่มคงที่ ไม่ใช่ข้อมูลจริง
- Engine วิเคราะห์ช่องว่างการเรียนรู้เป็น JavaScript แบบ deterministic ไม่ใช้ AI
- ไอคอนจาก Lucide (`svg-originals/lucide-icons`); แก้ `template.html` แล้วรัน `python3 build.py`
