# Classroom Pulse — Demo (static prototype)

เดโม UI แบบไฟล์เดียว เปิด `index.html` ได้ทันที
- ข้อมูลทั้งหมดเป็น **Demo Data** ในหน่วยความจำ (ไม่ใช้ Firebase, รีเฟรชแล้วรีเซ็ต)
- ไอคอนมาจาก Lucide ใน `svg-originals/lucide-icons` (ISC license) ฝังด้วย `build.py`
- แก้ `template.html` แล้วรัน `python3 build.py` เพื่อสร้าง `index.html` ใหม่
